# Legacy Implementation

This repository currently contains the original HyprVoice implementation.

It is based on Arch Linux + Hyprland + Quickshell and integrates directly into the illogical-impulse Quickshell configuration.

This version is now considered the **legacy implementation**. It is stable and working as designed. However, a new universal Python rewrite—designed to be standalone and support multiple distributions and environments—is planned separately. No runtime changes or breaking modifications will be introduced to this legacy branch.
